
## 현재 상황 분석

### "원문 없음" / "원문 미검증" / "링크 미검증"의 의미

| 라벨 | 의미 | 원인 |
|------|------|------|
| **원문 없음** (not_found) | 링크 접속 시 404 반환 | AI가 존재하지 않는 URL을 생성 |
| **링크 미검증** | 링크 검증 실패 (다양한 사유) | URL이 비어있거나 접속 불가 |
| **원문 링크 미확인** (no_verified_source) | 특허번호는 있으나 원문 링크 없음 | AI 제공 URL 검증 실패 |

### 핵심 문제: **콘텐츠가 가짜입니다**

현재 특허와 논문 데이터는 AI(Gemini)에게 "생성하세요"라고 요청하여 만든 것입니다. AI가 실제 존재하는 논문/특허를 인용하는 것이 아니라, 그럴듯한 제목·저자·특허번호를 **창작(hallucinate)**합니다.

- 특허: `US11843329B2` 같은 번호가 실제로 존재하는지 불확실
- 논문: `Journal of Electric Vehicle Powertrains` 같은 학술지가 존재하지 않을 수 있음  
- 링크가 빈 문자열 `""` → 검증 자체가 불가능

**이것은 링크 검증 로직의 문제가 아니라, 데이터 생성 방식 자체의 문제입니다.**

### 뉴스 데이터는 정상

뉴스(6,806건)는 RSS 크롤링으로 수집된 실제 기사이며, 모두 `link_verified: true`입니다. 트렌드 브리핑도 뉴스 기반이므로 출처 링크는 뉴스 DB의 검증된 URL을 사용합니다.

## 수정 계획

### 1. 특허/논문 생성 프롬프트를 "검색 가이드"로 전환

현재 AI에게 "실제 특허/논문을 생성하세요"라고 요청하지만, AI는 웹 검색 기능이 없어 할루시네이션합니다.

**변경**: AI에게 뉴스 기반으로 **기술 트렌드 분석 인사이트만** 생성하도록 하고, 개별 특허/논문 항목 생성을 중단합니다. 대신:

- **특허 페이지**: 기술 트렌드 인사이트 카드 + "Google Patents에서 검색" 버튼 (사용자가 직접 검색)
- **논문 페이지**: 기술 트렌드 인사이트 카드 + "Google Scholar에서 검색" 버튼 (사용자가 직접 검색)

### 2. 기존 가짜 데이터 삭제

DB에서 현재 저장된 특허/논문 데이터를 삭제하고, 인사이트만 남깁니다.

### 3. UI 업데이트

- Patents.tsx: 개별 특허 카드 목록 대신 인사이트 카드 + 검색 링크 UI
- Research.tsx: 개별 논문 카드 목록 대신 인사이트 카드 + 검색 링크 UI  
- "링크 미검증" 등의 배지가 더 이상 필요 없음

### 4. Edge Function 수정

- `analyze-market-data`: 특허/논문 개별 항목 생성 로직 제거, 인사이트 분석만 유지
- 검증 불가능한 개별 항목을 만들지 않으므로 가짜 콘텐츠 문제 원천 차단
